# Warning (markdown) on actionable variants/mutation hotspots removed by variant filtering, for the Key findings and variant filtering sections

Warning (markdown) on actionable variants/mutation hotspots removed by
variant filtering, for the Key findings and variant filtering sections

## Usage

``` r
filtering_warnings(s, max_show = 5)
```

## Arguments

- s:

  filtering summary, see filtering_summary()

- max_show:

  maximum number of variants listed per filtering type

## Value

character vector (one element per filtering type, empty if none)
