# Append note on imputed allele-specific copy number to segment hover info

Append note on imputed allele-specific copy number to segment hover info

## Usage

``` r
append_cna_imputed_info(cna_segments = NULL)
```

## Arguments

- cna_segments:

  data frame with copy number segments, with columns 'SegmentInfo' and
  'CN_MAJOR_MINOR_IMPUTED'
