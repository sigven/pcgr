# Biomarker databases used for actionability classification (as named in the HTML report)

Biomarker databases used for actionability classification (as named in
the HTML report)

## Usage

``` r
bm_db_label(report, fusion = FALSE)
```

## Arguments

- report:

  PCGR report object

- fusion:

  logical, RNA fusions (CGI evidence is never used for fusions)

## Value

character, e.g. 'CIViC and CGI'
