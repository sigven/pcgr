# MSI status as displayed in the report (MSI status cards)

Harmonizes the MSI status labels of the external MSI caller ('MSI-H',
'MSS', 'Indeterminate') and the PCGR MSI classifier ('MSI.H
(Microsatellite instability - high)', 'MSS (Microsatellite stable)') to
'MSI-high' / 'MSS' (other values unchanged)

## Usage

``` r
msi_status_display(status)
```

## Arguments

- status:

  MSI status (character)

## Value

display label (character)
