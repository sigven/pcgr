# Sentence on the biomarker databases used for tier assignment, appended to the actionability introductions (empty unless CGI is shown, but not used for tier assignment)

Sentence on the biomarker databases used for tier assignment, appended
to the actionability introductions (empty unless CGI is shown, but not
used for tier assignment)

## Usage

``` r
bm_db_tier_note(report, fusion = FALSE)
```

## Arguments

- report:

  PCGR report object

- fusion:

  logical, RNA fusions (CGI evidence is never used for fusions)

## Value

character
