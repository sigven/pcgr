# Character vector as Typst string literal content (escapes backslashes and double quotes), for values passed to Typst functions

Character vector as Typst string literal content (escapes backslashes
and double quotes), for values passed to Typst functions

## Usage

``` r
typst_str(x)
```

## Arguments

- x:

  character vector (NA as empty string)

## Value

character vector, to be placed between double quotes in Typst
