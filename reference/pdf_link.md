# Text as a link in a PDF report table cell (raw Typst markup; the column must not be escaped by format_tt())

Text as a link in a PDF report table cell (raw Typst markup; the column
must not be escaped by format_tt())

## Usage

``` r
pdf_link(label, url)
```

## Arguments

- label:

  link text(s)

- url:

  URL(s); NA for plain (escaped) text

## Value

character vector with Typst markup
