# Font settings for (static) ggplot2 figures of the PDF report - generic sans-serif font family and smaller text than the HTML report plots (which set 'Helvetica', not available on all systems)

Font settings for (static) ggplot2 figures of the PDF report - generic
sans-serif font family and smaller text than the HTML report plots
(which set 'Helvetica', not available on all systems)

## Usage

``` r
pdf_plot_theme(p, base_size = 9)
```

## Arguments

- p:

  ggplot2 object

- base_size:

  base text size (pt)

## Value

ggplot2 object
