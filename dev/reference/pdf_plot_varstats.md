# Donut charts of SNV/InDel variant statistics (coding status, variant type, consequence types) for the PDF report

Donut charts of SNV/InDel variant statistics (coding status, variant
type, consequence types) for the PDF report

## Usage

``` r
pdf_plot_varstats(report)
```

## Arguments

- report:

  PCGR report object

## Value

list of ggplot2 objects (coding consequence chart only when coding
variants are present)
