# Actionability tiers of prognostic and diagnostic biomarker evidence shown in the reports (HTML/PDF sections, key findings)

With a primary site, Tier 1/2 evidence is shown (evidence matching the
primary site). Without a primary site (site 'Any'), evidence from any
tumor type is considered, for which weak evidence (levels C/D/E) is
always Tier 3 - Tier 3 evidence is then also shown.

## Usage

``` r
progn_diagn_tiers(report)
```

## Arguments

- report:

  PCGR report object

## Value

integer vector of tiers
