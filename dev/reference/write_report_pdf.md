# Function that writes contents of PCGR object to a PDF report (Quarto/Typst-based), focused on key findings

Function that writes contents of PCGR object to a PDF report
(Quarto/Typst-based), focused on key findings

## Usage

``` r
write_report_pdf(report = NULL, color_palette = pcgrr::color_palette)
```

## Arguments

- report:

  List object with all report data, settings etc.

- color_palette:

  PCGR color palette
