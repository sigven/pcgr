# Citations of the biomarker databases used for actionability classification (pandoc citation keys, cf. bm_db_label())

Citations of the biomarker databases used for actionability
classification (pandoc citation keys, cf. bm_db_label())

## Usage

``` r
bm_db_citation(report)
```

- report:

  PCGR report object

## Value

character, e.g. '@Griffith2017-do; @Tamborero2018-aj'
