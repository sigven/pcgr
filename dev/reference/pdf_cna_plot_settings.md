# Copy number plot settings (tumor ploidy and effective amplification / gain / deletion thresholds) for the PDF report - as used for the copy number profile plots of the HTML report

Copy number plot settings (tumor ploidy and effective amplification /
gain / deletion thresholds) for the PDF report - as used for the copy
number profile plots of the HTML report

## Usage

``` r
pdf_cna_plot_settings(report)
```

## Arguments

- report:

  PCGR report object

## Value

list with tumor_ploidy, amp_threshold_effective, threshold_mode,
gain_threshold_effective and del_threshold_effective
