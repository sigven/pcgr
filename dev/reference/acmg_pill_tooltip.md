# Hover tooltip text of an ACMG criteria pill: description of the evidence code, and its contribution to the CPSR pathogenicity score

Hover tooltip text of an ACMG criteria pill: description of the evidence
code, and its contribution to the CPSR pathogenicity score

## Usage

``` r
acmg_pill_tooltip(code)
```

## Arguments

- code:

  ACMG evidence code, display form (e.g. "PVS1_strong")

## Value

tooltip text, or NULL for an unrecognized code
