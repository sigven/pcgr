# CPG_MOI (mode of inheritance) code(s) with their full names, for display in the row details of the germline findings table (e.g. 'AD/AR' -\> 'AD/AR (autosomal dominant / autosomal recessive)')

CPG_MOI (mode of inheritance) code(s) with their full names, for display
in the row details of the germline findings table (e.g. 'AD/AR' -\>
'AD/AR (autosomal dominant / autosomal recessive)')

## Usage

``` r
moi_display_text(x)
```

## Arguments

- x:

  CPG_MOI values (character)

## Value

character vector (NA for missing/empty values)
