# Variants located in a cancer mutation hotspot (cancerhotspots.org), as flagged in the HTML report (MUTATION_HOTSPOT_CANCERTYPE)

Variants located in a cancer mutation hotspot (cancerhotspots.org), as
flagged in the HTML report (MUTATION_HOTSPOT_CANCERTYPE)

## Usage

``` r
is_hotspot_variant(variants)
```

## Arguments

- variants:

  data frame with variants

## Value

logical vector (one element per row; FALSE if the hotspot column is
missing)
