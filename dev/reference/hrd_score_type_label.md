# Broad categories of HRD scores (HRD_SCORE_TYPE of an external HRD result)

Broad categories of HRD scores (HRD_SCORE_TYPE of an external HRD
result)

## Usage

``` r
hrd_score_type_label(score_type = NULL)
```

## Arguments

- score_type:

  HRD score type, one of 'genomic_scar', 'mutational_signature',
  'composite' or 'other'

## Value

label for display (NA for an unknown score type)
