# Main color of the PCGR report (tumor-control vs. tumor-only)

Main color of the PCGR report (tumor-control vs. tumor-only)

## Usage

``` r
pdf_report_color(report, color_palette = pcgrr::color_palette)
```

## Arguments

- report:

  PCGR report object

- color_palette:

  PCGR color palette

## Value

hex color (character)
