# Readable sample type labels of external (reference) samples, e.g. 'cell_line' - 'Cell line', 'primary_solid_tumor' - 'Primary solid tumor'

Readable sample type labels of external (reference) samples, e.g.
'cell_line' - 'Cell line', 'primary_solid_tumor' - 'Primary solid tumor'

## Usage

``` r
format_sample_type(x)
```

## Arguments

- x:

  sample types (character)

## Value

character vector (NA kept)
